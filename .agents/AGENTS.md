# Workspace Rules

- **Granular, Honest Commits**: Commit corrections individually and specifically (e.g., `fix: correct gravity sign in symbolic EOM derivation (verified against Pendulum Equations.pdf)`). Use small, honest, traceable commits instead of a single giant verification/squash commit.
- **Verification Status Consistency**: Never commit lab modules as "done" or "completed" in a way that implies verification unless verified. Ensure commit messages and README status markers (e.g., `## Verification status`) strictly agree at all times.
